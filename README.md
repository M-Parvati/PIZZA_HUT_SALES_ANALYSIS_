## 🍕 PIZZA_SALES_ANALYSIS_USING_SQL

# Overview:

This project analyzes a historical pizza sales dataset to uncover key business insights related to revenue generation, order patterns, and product performance.

The goal is to leverage SQL for data-driven decision-making by identifying top-selling pizzas, understanding size preferences, and tracking sales trends over time.

# Steps Included in the Project:

## 1. Data Preparation & Understanding:

Explored relational tables — orders, order_details, pizzas, and pizza_types.

Understood the relationships between orders, pizza sizes, and pizza categories.

Ensured data consistency for joins and aggregation operations.

## 2. SQL Data Analysis:

Joined multiple tables to create a unified view of sales data.

Performed aggregation using GROUP BY, JOIN, and ORDER BY clauses to compute KPIs such as:

Total Orders: 21,350

Total Revenue: $817,860.05

Average Pizzas Sold per Day: 138.47

Most Popular Size: ‘L’ (18,526 orders)

## 3. Revenue & Performance Insights:

Identified Top 3 Pizzas by Revenue — The Thai Chicken Pizza led with $43,434.

Found Highest-Priced Pizza — The Greek Pizza ($35.95).

Analyzed Category-Wise Revenue Contribution:

Classic – 26.91%

Supreme – 25.46%

Determined hourly order distribution, with a peak at 11 AM (1,231 orders).

## 4. Advanced SQL Techniques:

Applied window functions to calculate cumulative revenue trends.

Used CTEs for cleaner query structuring.

Grouped orders by date to analyze daily sales averages and time-based patterns.

# Tools & Techniques Used:

SQL (MySQL) — Data Querying & Aggregation

Joins | Group By | Window Functions | CTEs | Order By | Subqueries

# Key Insights:

Total Orders: 21,350 | Total Revenue: $817,860.05

Top Pizza by Revenue: The Thai Chicken Pizza ($43,434)

Average Pizzas Sold per Day: 138.47

Most Common Size: Large (L)

Major Contributors: Classic (26.91%) and Supreme (25.46%)

# Recommendations:

Focus marketing on Classic and Supreme categories, which contribute over 50% of revenue.

Analyze time-based ordering to optimize staffing during peak hours (around 11 AM).

Introduce offers on smaller sizes to balance size preference distribution.

# Conclusion:

This SQL-based Pizza Sales Analysis demonstrates how advanced querying, aggregation, and analytical SQL techniques can transform raw transactional data into actionable business insights.

The project highlights the importance of data-driven decision-making for understanding customer behavior, improving product performance, and optimizing sales strategy.
